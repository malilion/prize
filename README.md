# 抽獎轉盤

離線可用的抽獎轉盤：設定獎池與名單、投影轉盤抽獎、每一抽自動錄影存證，最後匯出中獎名單與完整憑證包。支援場次備份還原與另一台電腦離線驗證憑證包。
不需要安裝任何東西，也不需要網路。

**線上版：<https://malilion.github.io/prize/>**

## 開始使用

1. 用 **Chrome、Edge 或 Safari** 開啟[線上版](https://malilion.github.io/prize/)，或下載後直接雙擊 `index.html`（完全離線可用）。
   兩者的資料各自分開保存，活動請固定用同一個；要換之前先匯出憑證包。
2. 第一次開啟會載入範例資料，按右側的「清除範例資料」換成自己的。
3. **獎池**：新增獎項與名額。每個獎項可限定組別，並設定曾中獎者能否再次參加。由上而下依序抽，抽完一項會自動換下一項。
4. **名單**：每行一位，可直接從 Excel 貼上，或匯入 `.txt` / `.csv`（UTF-8、Big5 都可以）。分組請用 `姓名 | 組別`，例如 `A001 陳怡君 | 業務部`。CSV 有「姓名」表頭時只取姓名與可選的組別；沒有辨識到表頭時才合併欄位。
5. 到「設定」執行**活動前檢查**與**隔離預演**。檢查會合計排除重複中獎的獎項名額與組別需求；設定或紀錄改變後須重新檢查。預演會轉動轉盤、試錄一段影片後立即丟棄，不會寫入紀錄或占用名額。
6. 按「開始抽獎」或空白鍵。上台投影時可按「簡報模式」（或 F 鍵）全螢幕，或按「開啟投影視窗」把畫面拖到另一個螢幕；操作台留在原視窗。
   首次抽獎後，名單與「中獎的人不再參加」設定會鎖定；重設抽獎後可再編輯，原名單會保留。
7. 活動結束到「紀錄」分頁：
   - **匯出中獎名單**：CSV，Excel 直接開；抽出時間以 UTC 的 ISO 8601 格式記錄，方便跨時區驗證。
   - **匯出憑證包**：ZIP，內含名單、場次狀態、完整稽核紀錄、可取得的錄影與 SHA-256 雜湊值。
8. 在「設定 → 場次移轉」可隨時匯出備份 ZIP（尚未抽獎也可以），或選擇 ZIP 還原場次。還原會取代目前場次，介面會先顯示摘要並要求輸入「還原」。

快捷鍵：空白鍵／Enter 開始抽獎・F 簡報模式・Esc 收起中獎畫面。

## 錄影憑證怎麼運作

- 每一抽都會自動錄下轉盤畫面（1920×1080、30 fps，含音效），從轉動前 1 秒錄到結果後 3 秒。
  錄下的就是現場投影的同一個畫面。
- 畫面下方固定顯示：**場次代碼、抽次、候選人數、名單指紋、亂數來源與精確到 0.1 秒的時間**，
  左上角有 REC 計時。
- 錄完會自動下載（可在「設定」關閉），同時存在瀏覽器裡，重新整理也不會消失。
- 如果影片已存入瀏覽器，但頁面在錄影狀態寫回前中斷，重新開啟時會核對影片 SHA-256 並恢復可播放、下載的紀錄；「活動前檢查」也可重試恢復。
- 每段錄影的 **SHA-256** 記在中獎名單與稽核紀錄中。之後任何人都能驗證影片沒有被剪輯或修改：
  - 在「紀錄 → 驗證錄影檔」選擇影片，自動比對；或
  - 解開憑證包後在資料夾執行 `shasum -a 256 -c SHA256SUMS.txt`（macOS／Linux）。
  - 開啟 [獨立驗證頁](verify.html)，直接選擇 ZIP；它會檢查 ZIP 校驗、CSV 的時間與備註、候選名單與中獎位置、錄影 SHA-256，以及場次備份與稽核紀錄是否一致。舊版憑證包的 CSV 時間未標示時區，驗證頁會顯示限制。若活動時另行公開了整包 ZIP 的 SHA-256，可貼上比對。
- **名單指紋** 是該抽候選名單的 SHA-256。稽核紀錄 `抽獎紀錄.json` 保存每一抽當下的完整候選名單，
  可以重算比對，確認某人當時確實在名單裡。

## 公平性與紀錄完整

- 中獎者用瀏覽器的 `crypto.getRandomValues()` 以拒絕取樣抽出，每位候選人的機率完全相同；
  轉盤只是把結果轉出來，停下的格子一定是抽出的那一位（程式會再核對一次）。
- 抽次連續編號、不能刪除：
  - **作廢**（例如得獎者未到場）：紀錄與錄影保留並標示作廢，獎項釋出名額可以重抽。
  - **中斷**：若抽獎轉到一半頁面被關閉，這一抽會以「中斷」保留原本抽定的結果，不會無聲消失。
- 「重設抽獎」會清除紀錄並換新的場次代碼，必須輸入「重設」確認；建議先匯出憑證包。
- 使用 IndexedDB 時，重設或還原會先保存新場次的錄影資料，場次切換成功後才清理舊錄影；若在切換前關閉頁面，原場次仍可讀取。
- 每抽保存實際候選名單、候選識別鍵及當時的組別／重複中獎規則。獎項開始抽出後，其資格規則會鎖定。
- 若瀏覽器無法保存預定結果，抽獎會暫停，避免轉盤已抽出但重新整理後紀錄消失。檢查儲存權限或可用空間後，可到「設定」重試儲存。
- 若既有場次資料損壞或版本不相容，頁面會暫停寫入，提供原始資料下載；可在「設定 → 場次移轉」用已驗證的備份還原。
- 轉盤停止後會先保存有效中獎狀態，再公布結果；若這一步失敗，該抽標記為中斷並暫停後續抽獎。作廢狀態若保存失敗，也會回復為有效紀錄。
- 同一場次的抽獎會取得跨分頁鎖定；另一個分頁已修改紀錄時，舊分頁會停止寫入並要求重新整理，避免覆蓋較新的結果。

## 資安

- 完全離線：沒有外部資源、CDN 或第三方套件；Content-Security-Policy 只允許載入本機的程式與樣式。
- 所有名字、獎項都以跳脫後的文字顯示，不會被當成 HTML 執行；匯出的 CSV 會擋掉以 `=`、`+`、`-`、`@` 開頭的試算表公式。
- 檔名會移除路徑字元，憑證包裡的檔案不會跑出資料夾；瀏覽器裡保存的資料每次載入都會重新檢查格式。
- 雜湊值是在抽獎的電腦上產生的。要讓它成為有效的憑證，請在每一抽後或活動結束時，立刻把中獎名單（含 SHA-256）傳給參加者或群組，公開之後就無法再竄改。
- 匯出憑證包後，「紀錄」會顯示整份 ZIP 的 SHA-256。可將這個值發布在獨立管道；驗證者下載 ZIP 後，可在獨立驗證頁輸入已公開的值，確認整包未被替換。
- 憑證包與錄影含完整名單與中獎者姓名，屬於個人資料，請不要公開上傳。
- 獨立驗證確認憑證包內部資料一致，不能單靠整包資料證明抽獎當時使用的程式或檔案從未被整包重建；若需對外公信力，請在抽獎當下公開並留存雜湊值。

## 注意事項

- 抽獎時請保持這個分頁在前景；切換分頁會讓瀏覽器暫停畫面更新，影片會卡住。
- 分離投影視窗逐幀複製操作台錄影畫布；請保持操作台分頁在前景，並在正式活動前於現場雙螢幕測試瀏覽器的視窗權限與效能。
- 錄影格式依瀏覽器而定：Chrome／Edge／Safari 為 MP4（H.264），Firefox 為 WebM。
- 憑證包使用標準 ZIP 格式，總大小不能超過 4 GB；超過時請個別下載錄影。
- 資料只存在這台電腦的瀏覽器裡（localStorage + IndexedDB），不會上傳到任何地方。
  換電腦或清除瀏覽器資料前，請先匯出憑證包。
- 若瀏覽器無法使用 IndexedDB，候選名單快照與錄影只暫存在記憶體；請每抽後匯出憑證包，重新整理後無法補回。
- 跨分頁鎖定需要 Web Locks 或 IndexedDB；兩者都不可用時會暫停正式抽獎。活動請只開一個操作分頁，投影請使用頁面內的獨立投影功能。
- 一次抽一位；同名的人會各自參加（名單分頁會提示重複）。
- 匯出憑證包時會鎖定同一場次的抽獎、重設與還原，並在下載前檢查其他分頁是否更動資料。

## 檔案結構

```
index.html        頁面結構
tokens.css        顏色、字體、間距等設計參數（轉盤畫面的顏色也從這裡讀）
app.css           版面與元件樣式
js/util.js        格式化、亂數、SHA-256、CSV、色彩轉換
js/zip.js         憑證包 ZIP 產生器
js/evidence.js    ZIP 讀取後的憑證一致性檢查
js/eligibility.js 名單分組與獎項資格計算
js/store.js       localStorage 與 IndexedDB 儲存
js/sound.js       合成音效（同時送進錄影）
js/recorder.js    畫面錄影（MediaRecorder）
js/stage.js       1920×1080 轉盤畫面繪製與轉動動畫
js/app.js         狀態、面板、抽獎流程、匯出
verify.html       獨立離線驗證頁
projection.html   分離投影頁
```
